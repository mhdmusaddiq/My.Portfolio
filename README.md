# Muhammed Musaddiq Portfolio

Personal portfolio for **Muhammed Musaddiq** — Software Engineer, **Co-Founder of X10 THINK**, and **IoT Engineering Student**.

## Run locally
Open `index.html`, or serve the folder with any static server.

## Deploy
This is a static site and can be deployed directly to Vercel, Netlify, GitHub Pages, or another static host.

## Main files
- `index.html` — portfolio content and structure
- `style.css` — responsive design and three interface themes
- `script.js` — preloader, themes, tabs, skill universe, live lab, assistant, command menu, contact flow
- `assets/musaddiq-profile.webp` — portfolio portrait
